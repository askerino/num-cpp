# num-cpp {#mainpage}

A header-only C++ numerical computing library written for learning.

It was created to learn the fundamentals of C++ and numerical computing. Real projects would normally use established libraries such as Eigen; the goal here is to understand how the algorithms work internally. The code does not rely on any external libraries and stays close to the underlying mathematics.

See the [README](https://github.com/askerino/num-cpp#readme) for more details.
